About Cineverse

Cineverse is an IPTV web application built for a Java PBL. The backend is pure Java (JDK only), the frontend is HTML, CSS and JavaScript.

How it works

  1. User pastes a playlist link in the browser.
  2. Frontend calls /api/channels?url=....
  3. Java HttpClient downloads the M3U file.
  4. A regex parser reads each #EXTINF line (name, logo, group) and its stream URL.
  5. Channels are sent back as JSON and shown as a searchable grid.
  6. On play, /proxy relays the stream through Java (avoids CORS) and rewrites .m3u8 links.
  7. hls.js plays the stream in the HTML5 video player.

Tech stack

Java 17: HttpServer, HttpClient, regex, nio.file

Frontend: HTML5, CSS3 (grid, flexbox, animations), JavaScript, hls.js
